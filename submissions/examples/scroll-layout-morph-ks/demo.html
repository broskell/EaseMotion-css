Modern CSS Technique

Scroll-Driven
Layout Morph

Cards and containers that change their grid layout, border-radius, gap, and padding as you scroll. Every layout property is controlled by @property-registered custom properties driven by animation-timeline. Zero JavaScript.

Scroll to morph
Technique 1

Border Radius
That Morphs

Cards that transition from rounded badges to sharp panels as the section enters the viewport. @property --morph-radius registered as <length> enables smooth interpolation of border-radius from 50% to 0.5rem — transforming card shape continuously with scroll position.

◆

Radius Morph

The card shape changes as you scroll through this section.

◆

Fluid Transition

Every pixel of scroll directly affects the border-radius value.

◆

@property Powered

Without @property, border-radius cannot animate between percentage and length.

Technique 2

Grid Gap
That Collapses

Cards that start widely spaced and collapse together as you scroll. @property --morph-gap controls the grid gap property, animating from 3rem to 0.5rem. The cards visually group together in response to the user's scrolling behavior.

◆

Wide Start

Cards begin with generous spacing at the top of the viewport.

◆

Gradual Close

The gap shrinks continuously as you scroll further down.

◆

Tight Group

Cards cluster together for a dense layout at the bottom.

Technique 3

Padding
That Expands

Cards that grow in padding as you scroll — from compact cards to spacious content containers. @property --morph-padding animates from 0.75rem to 2.5rem, giving the cards room to breathe as the user engages deeper with the page.

◆

Compact Start

Cards begin tight and condensed at the section entrance.

◆

Breathing Room

Padding grows alongside scroll progress — more space for content.

◆

Spacious Focus

Maximum padding for maximum readability at the section bottom.

Technique 4

Grid Columns
That Reorganize

A grid that changes its column structure as the user scrolls — from a single column to three columns. @property --morph-columns controls grid-template-columns with repeat(var(--count), 1fr), transitioning smoothly through intermediate states.

◆

One Column

Starts as a single-column list that stacks vertically.

◆

Two Column

The grid splits into pairs as the section enters view.

◆

Three Column

Full three-column layout emerges at the section center.

CSS APIs Used

The modern CSS primitives powering scroll-driven layout morphing
API Role Support
@property Registers typed custom properties — enables smooth interpolation of border-radius, gap, padding, and grid columns Chrome 85+, Safari 16.4+, Firefox 128+
animation-timeline: view() Links layout property animation to element visibility within the scroll container Chrome 115+, Safari 18+
animation-range Controls the scroll range where layout morphing is active Chrome 115+, Safari 18+
border-radius Animates between different shapes — circle to rounded rect All modern browsers
grid-template-columns + gap Grid structure that reorganizes based on scroll-driven property values All modern browsers

In browsers without @property or animation-timeline support, static fallback values provide a fully functional layout at all screen sizes.
